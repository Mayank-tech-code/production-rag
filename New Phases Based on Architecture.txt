1. Create a Virtual ENV 
	python -m venv .venv --without-pip  --------- it will create a venv folder under project root 

2. Verify it was created 
	Test-Path .venv\Scripts\python.exe ======== True

3.Test-Path .venv\Scripts\Activate.ps1
	Expected -------- True

4.Activate the environment
	.\.venv\Scripts\Activate.ps1
	(.venv) PS C:\Users\ASUS\Desktop\Enterprise RAG\new-project>
	The important part is: (.venv)

5.Install pip
	Because we created the environment using --without-pip, run:
	python -m ensurepip --upgrade
	Then: python -m pip install --upgrade pip
6. Verify
 	Run:	python --version
	Expected: Python 3.11.9
	Then:	python -m pip --version
	It should point somewhere inside:
	...\new-project\.venv\Lib\site-packages\pip
	Finally:
	where.exe python
	The first result should be:
	C:\...\new-project\.venv\Scripts\python.exe
